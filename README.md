# Sri Vidya E.M. School — Final Website

Clean production project prepared from the CMS-connected project.

## Included
- React + Vite website
- CMS API
- Vercel Blob integration
- Local school assets
- User-uploaded gallery images
- Exact latest user-supplied Principal image
- User-supplied school logo
- Temporary content-specific design images for academic/facility/activity image slots
- sitemap.xml and robots.txt
- Vercel configuration

## Important
- `node_modules` is intentionally excluded. Run `npm install` after extracting.
- No `.env` secrets are included.
- Set Vercel environment variables before using CMS write/upload features.
- Custom domain/DNS is still a separate final connection step.
